# История изменений

Все значимые изменения MedTools Identity API документируются в этом файле.

## [0.1.0] — 20.10.2026

### Добавлено

- Централизованная аутентификация пользователей с выдачей JWT-токенов.
- Подпись JWT-токенов с использованием алгоритма RS256.
- Ролевая модель управления доступом (RBAC).
- Управление пользователями и их учётными записями.
- Управление организациями.
- Управление ролями и разрешениями.
- Проверка разрешений при обращении к защищённым маршрутам API.
- Получение информации о текущем аутентифицированном пользователе.
- Хранение данных с использованием Entity Framework Core и Microsoft SQL Server.

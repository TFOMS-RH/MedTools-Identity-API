# MedTools Identity API

**MedTools Identity API** — централизованный сервис аутентификации, управления пользователями и контроля доступа в корпоративной платформе MedTools.

Сервис предоставляет единый механизм идентификации пользователей и авторизации запросов для приложений и API платформы.

## Основные возможности

Основные задачи сервиса:

- **Authentication** — аутентификация пользователей и выдача JWT-токенов.
- **User Management** — управление пользователями и их учётными записями.
- **Organization Management** — управление организациями и принадлежностью пользователей к ним.
- **Role Management** — управление ролями и назначением прав доступа.
- **Permission Management** — разграничение доступа к функциональности платформы на основании разрешений.

## Аутентификация и авторизация

Для аутентификации используется механизм JWT (JSON Web Token) с цифровой подписью **RS256**.

Авторизация основана на модели **Role-Based Access Control (RBAC)**.

Роли объединяют разрешения, определяющие доступ пользователя к операциям системы. Проверка необходимых разрешений выполняется на уровне защищённых API endpoints.

## Технологический стек

- **.NET 10 / ASP.NET Core Minimal API**
- **Entity Framework Core**
- **Microsoft SQL Server**
- **JWT / RSA (RS256)**
